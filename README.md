# 西多摩地域 感染症流行状況 draft-01

横浜版の2疾患カード構成を西多摩向けに再構成した候補コードです。

判定: 1未満=非流行(緑)、1以上10未満=流行中(黄)、10以上30未満=注意報レベル(赤)、30以上=警報レベル(紫)。

`data/status.json` は画面確認用のサンプル値です。東京都のWEB感染症発生動向は各保健所別データをダウンロード可能ですが、取得URL/API形式をこの成果物では未確定のため `update_status.py` は安全な雛形に留めています。

画像は既存横浜版と同名の `assets/handwash.png`, `healthcheck.png`, `ventilation.png`, `mask.png` を配置してください。
